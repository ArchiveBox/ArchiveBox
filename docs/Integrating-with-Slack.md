- **@mention the bot** → save URLs from your message and the latest 10 messages.
- **DM the bot** → save the URLs you send.
- **Post in New URLs** → archive shared links with separate provider, sender, and channel/group tags.
- **Open Saved URLs** → titles, screenshots, original links, sizes, and personas.
- **Enable a group** → archive every link shared there.

**Connect:** ArchiveBox URL + API key → chat account → choose conversations.

[Open the setup guide →](https://github.com/ArchiveBox/archivebox-chat-bot#connect-your-apps)

## ArchiveBox AI Bot

<a href="https://github.com/ArchiveBox/archivebox-chat-bot/blob/main/screenshots/slack-ai-task.jpg"><img src="https://raw.githubusercontent.com/ArchiveBox/archivebox-chat-bot/main/screenshots/slack-ai-task.jpg" width="720" alt="Real Slack AI task: plan a caching collection, capture missing references, tag snapshots, and verify results"></a>

- **DM or @mention the AI bot** → research, capture, organize, and verify your archive.
- **Use your existing OpenCode setup** → providers, tools, credentials, and saved sessions.
- **Open ArchiveBox → Agent** → inspect each task and its results.
- **Connect a second bot/account** → choose the people allowed to run agent tasks.

[Connect ArchiveBox AI Bot →](https://github.com/ArchiveBox/archivebox-chat-bot#connect-the-ai-bot)
